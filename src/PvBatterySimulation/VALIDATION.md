# Implementation and validation record

Completed on 29 September 2026, based on main commit `0d0a9c3`. This is the backend-only validation checkpoint. The PV Autonomy UI and package were added later; see [current application usage](../ApplicationFrontend/RUNNING.md) and the [4 October review](../../docs/SOURCE_AND_EXPORT_REVIEW_2026-10-04.md).

## Implemented scope

- Six-input energy-balance engine with continuous battery state and hourly end-of-hour SoC.
- Explicit interval/timezone handling, input validation, cancellation, unmet load and curtailment diagnostics.
- Independent core, existing `PanelRun` adapter and final shaded-panel XLSX adapter.
- CSV/JSON/XLSX exports with units, settings and provenance.
- Analytical tests, frozen two-day fixture, decimal reference checks and offline validator.
- Backend solution integration and API/assumption documentation.

At this checkpoint, application UI wiring and packaging a new application release were deferred; both were subsequently implemented. Literature/industrial-tool comparison and physical validation remain open. The module's software verification does not establish real-world outage probability.

The saved workbook run used `src/ApplicationFrontend/Example/Debug Data/reference-run/06-shading/panel-shaded.xlsx`, `Fixtures/example-settings.json` and `Asia/Ho_Chi_Minh`. It finished at 69.421% SoC, with zero unmet load and 20,716.023755 Wh curtailed, under the deliberately small example system settings. This is an adapter/transport check, not a recommended system design.

The first 14 analytical tests were run against an unimplemented engine and failed before implementation; they subsequently passed. The wider suite checks ideal battery discharge separately from PV conversion, all-hour continuity, saturation before averaging, elapsed duration, local load alignment, DST, nonfinite/missing data rejection, snapshots and export precision. The frozen fixture's expected values are not generated by the production simulator.

Raw test reports and validator exports are generated under ignored `artifacts/pv-battery*` directories. Reproduction commands and the exact model are in [README.md](README.md).
