## Items already implemented: verify rather than duplicate

- **Edited mask → calculation/export**: `AppServices.PrepareImageStages` loads a selected immutable variant's bytes before the AI branch. `MaskEditingTests.SelectedEditFeedsShadingAndExportAndAiCanBeRestored` verifies selected pixels, numerical effects, exported provenance and return to an accepted original result. W1 fills the separate independent-import gap.
- **Explicit update and stale results**: already implemented in the manual-update/controller work. Changes invalidate dependent output without immediately downloading or recalculating. W7 makes the existing behavior understandable.
- **Shared orientation**: camera projection, shading, sun paths and compass overlays share the calibrated camera convention. Analytical tests establish N top/E left/S bottom/W right at upward/default pose and the +90° roll example. Explaining this is W6; changing handedness from a report picture alone is unjustified.
- **Shaded XLSX output**: current library writes `Debug Data/06-shading/panel-shaded.xlsx`; the verified scenario export copies it unchanged. `PanelCorrectionTests.SourceCadenceAndActualDurationSurviveCorrectionAndNativeExports` checks hourly and 15-minute intervals, stable IDs/durations, workbook metadata and a numerical cell read back from the XLSX ZIP. Frontend export tests verify exact artifact bytes and refuse stale/incomplete output. Hourly inputs remain hourly; integration samples do not add weather rows. No new export format is required for the request on PDF p. 15.

## Scientific follow-ups outside this GUI fix set

1. **White/half-black loss discrepancy** (PDF pp. 18–19). Text says approximately 10%, but screenshots show **19.4%** for the white disk and **19.1%** after the half-black image was re-segmented. Capture original photo/mask, effective calibration and disk, coverage limit, panel/camera pose, site/zone/period, source intervals, diffuse model and actual selected pixels before drawing a conclusion. Compare synthetic fully observed open/blocked/half masks and measured coverage. FOV is a hypothesis; changing it to force zero loss is not an accepted fix. Imported masks now make the intended experiment possible.
2. **Vietnam trajectory** (PDF p. 15). The note does not provide a complete reproducible case. Preserve the reported location/period/time zone and physical camera orientation, compare shared projection to independent solar positions, and confirm photo rotation/mirroring. Existing synthetic orientation regressions are useful but cannot validate an unidentified original screenshot.

Neither unresolved scientific issue is claimed fixed by the interface changes. No-shading numerical correctness for the original case requires those missing original inputs.
